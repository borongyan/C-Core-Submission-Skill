> A full workflow skill for CSSCI & Chinese Core Journal Submission (Social Sciences)
> 面向人文社科青年学者、博士生的 C刊 / C扩 / 北大中文核心 投稿选刊全流程工作技能

## 📖 简介
本仓库整理一套可复用的学术投稿工作流 Skill，融合大量一线投稿经验，解决博士生、双非青年学者常见痛点：
- 盲目海投、不会精准匹配期刊栏目
- 不熟悉青年友好型C刊、独作友好期刊
- 选题不会“热中找冷”、文献综述写成清单、理论与案例两张皮
- 不了解投稿时间、格式、邮件、引用等实操细节
- 缺少期刊口碑库，踩坑周期长、不知道哪些期刊容易吊着稿件

✅ 适用学科：马克思主义理论、思政、公共管理、经济学、金融学、社会学、文学等人文学科
✅ 覆盖刊物：CSSCI正刊 / CSSCI扩展版 / 北大中文核心 / CSSCI集刊（单独标记风险）
⚠️ 免责声明：本仓库仅为经验总结，**不保证录用**；期刊目录、栏目、审稿规则随时变动，投稿前以期刊官网、CSSCI官方目录为准。
